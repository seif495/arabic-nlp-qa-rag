# Model A Architecture Card

Model A implements ADR §2: a no-attention tri-encoder gated-fusion seq2seq model with a FiLM-conditioned LSTM decoder.

Layer summary:

- Shared BPE embedding: `4096 x 128`, tied with decoder output projection by live variable reference.
- Branch 1: question embedding -> BiLSTM(96) -> masked structured pooling -> `(B, 192)`.
- Branch 2: context embedding -> BiGRU(96) -> BiGRU(96) -> `(B, L_c, 192)`.
- Branch 3: joint BPE embedding plus char-CNN kernels `{2,3,4}` -> BiLSTM(96) -> `(B, L_enc, 192)`.
- Alignment: per-example `question_length + 2` gather slices Branch 3 to context positions.
- Gated merge: three projected experts, local softmax over branch identity, dropout, layer norm.
- Refinement: BiGRU(96) -> `encoder_output (B,L_c,192)` and `encoder_summary (B,192)`.
- FiLM: `encoder_summary -> Dense(128,GELU) -> Dense(512)`, identity-initialized gamma/beta.
- Decoder: two LSTM(256) layers with FiLM after each layer; output projection maps 256 -> 128 then multiplies by `E^T` plus output bias.

Parameter budget: ADR §2.14 target is approximately 2.7M, accepted range `[2.4M, 3.0M]`. Exact audit is generated by `write_parameter_audit` in a TensorFlow-capable runtime.
